# Engine-Sound-Classification-via-Leakage-Aware-Deep-Audio-Learning

## Description

This project focuses on the classification of engine sounds using deep audio learning techniques with a leakage-aware approach. The primary objective is to develop robust machine learning models that can accurately identify and classify different types of engine sounds while addressing potential data leakage issues that commonly affect audio classification tasks.

The leakage-aware methodology ensures that the model generalizes well to unseen data by preventing information from the test set from inadvertently influencing the training process. This is particularly important in audio applications where temporal dependencies and overlapping samples can lead to overfitting and inflated performance metrics.
